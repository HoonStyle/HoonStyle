## What I build

- **[legacy-spec-agent](https://github.com/HoonStyle/legacy-spec-agent)** —
  Claude Code / Codex plugin that generates citation-backed (`path:line`)
  specifications from legacy code. Separates LLM reasoning from deterministic
  evidence checks and tracks citation validity as code changes. Published
  evaluations document both citation accuracy and gaps in coverage. MIT.
- **[greplet](https://github.com/HoonStyle/greplet)** —
  Local hybrid search for code and specification documents, combining vector
  search and BM25. Returns source locations rather than generated summaries,
  with workspace indexing and MCP integration for AI coding agents. MIT.
- **[tierwork](https://github.com/HoonStyle/tierwork)** —
  Claude Code / Codex plugin for delegating review tasks and tracking their
  execution. Makes worker roles, review results, and reuse decisions explicit
  so completed work can be distinguished from proposed or skipped checks.
- **[OhMoney-portfolio](https://github.com/HoonStyle/OhMoney-portfolio)** —
  Architecture and product-decision record of a 20-agent LLM orchestration
  system I planned, built, and operated as personal R&D. Covers LangGraph
  control flow, automated grading, model-routing policies, and staged
  pipelines with retries and fallbacks.
